# SaveMe Website

A static, mobile-friendly SaveMe website prepared for GitHub Pages.

## Files
- `index.html` — home page
- `blog.html` — blog/articles
- `privacy-policy.html` — privacy policy starter
- `terms.html` — terms & conditions starter
- `contact.html` — support contact
- `assets/saveme-logo.png` — SaveMe logo
- `styles.css` — site styling

## GitHub Pages
1. Create a public GitHub repository, for example `saveme-site`.
2. Upload all files in this folder to the repository root.
3. In GitHub: Settings → Pages.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. GitHub will give you a free `https://YOUR-USERNAME.github.io/saveme-site/` address.

## Important legal note
The Privacy Policy and Terms are intentionally written as a safe starter framework because the exact SaveMe data practices and legal entity/jurisdiction were not provided. Before publishing them as final legal documents, update them to match the actual app (permissions, location, contacts, accounts, analytics, notifications, emergency features, third-party SDKs, retention, etc.) and have them reviewed when appropriate.
